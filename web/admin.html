邮箱验证与找回密码

—

找回密码要同时满足三件事：开启邮箱验证 + 发信配置完整 + 该用户已绑定邮箱。 开关关闭时，即使用户绑过邮箱也不会发送任何邮件；未绑定邮箱的用户，页面会提示联系管理员重置。 「强制使用邮箱注册」是独立开关：开启后注册必须完成邮箱验证码校验，同样要求下方发信配置完整。

开关
开启邮箱验证
开启后，用户可在「我的」里绑定邮箱，并可用邮箱验证码找回密码。 开启前必须先把下方发信配置填完整，否则保存会被拒绝 —— 避免出现「开关是开的、邮件却发不出去」的假可用状态。
强制使用邮箱注册
开启后注册页必须填写邮箱并完成验证码验证才能注册成功；注册后的邮箱可直接当账号登录。 默认关闭，关闭时注册流程与以前完全一致，已有账号不受影响。此开关同样要求发信配置完整。
发信服务器（SMTP）
发信地址

邮件头里的 From，通常是你的邮箱地址；留空则无法开启邮箱验证。

发信人名称

收件人看到的显示名，可留空（只显示邮箱地址）。

SMTP 服务器

只填域名或 IP，不要带 smtp:// 或路径。

端口 / 加密方式

QQ / 163 邮箱用 SSL + 465；企业邮箱常见 STARTTLS + 587。

SMTP 账号

通常是完整邮箱地址；内网中继不需要认证时留空。

密码 / 授权码

已保存时留空表示不修改。

QQ / 163 邮箱要在设置里开启 SMTP 并生成「授权码」，不能用登录密码。

保存与测试

测试邮件直接用当前表单里的值发送（密码留空则用已保存的），不需要先保存。
